# DustySearch 路线图

这个路线图不是承诺清单，而是接下来最值得继续打磨的方向。优先级会根据真实用户反馈调整。

## 近期优先

### 1. 更顺手的 Windows 下载体验

现在 v1.0.0 提供的是 zip 包，用户需要解压后运行 `Start-DustySearch.cmd`。

后续希望提供更简单的安装方式：

- 一键安装包。
- 更清楚的首次启动说明。
- Windows 安全提醒的解释。

### 2. 更好的首次使用引导

当前软件已经有上手引导和资料体检，但新用户可能还是会问：

- 我应该先搜，还是先导入？
- 哪些资料会被搜索？
- 正文搜索和记忆库有什么区别？

后续会继续减少这些疑惑。

### 3. 搜索结果继续打磨

当前搜索结果已经有分组、预览、命中原因和弱结果提示。

后续可以继续优化：

- 更清楚地区分“文件名命中”和“正文命中”。
- 搜索结果很多时更好筛选。
- 对图片 OCR、网页资料、收藏资料给出更明确的来源说明。

### 4. 更多真实格式测试

目前支持 TXT、Markdown、PDF、Word、Excel、CSV 和图片 OCR。

后续需要根据真实反馈继续测试：

- 大 PDF。
- 扫描版 PDF。
- 更多 Excel 表格场景。
- 中文文件名、长路径、网盘同步文件夹。

## 中期方向

### 1. 更轻的发布包

当前 Windows zip 包包含运行所需文件，体积偏大。

后续希望：

- 减小下载包体积。
- 提供更标准的安装器。
- 保持普通用户下载后能直接使用。

### 2. 记忆库整理能力

记忆库现在支持分类、标签、备注和搜索。

后续可以继续加入：

- 批量改分类。
- 常用标签建议。
- 重复资料提醒。
- 更方便的导出和迁移。

### 3. 更清楚的隐私提示

DustySearch 是本地优先软件，但用户第一次使用时可能仍会担心数据去哪里。

后续可以在界面里更明确说明：

- 哪些数据保存在本机。
- 哪些操作会打开浏览器。
- 网页摘要如何关闭。
- 云同步不会登录账号。
