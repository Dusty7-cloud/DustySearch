## 一句话介绍

DustySearch 是一个 Windows 本地资料搜索和记忆库软件，可以搜索文件名、PDF/Word/Excel 正文、截图 OCR 文字、导入网页和收藏资料，数据默认保存在自己电脑上。

- 一个本地优先的 Windows 资料搜索工具：文件、正文、截图 OCR、网页都能搜

- DustySearch：把本机文件、截图、网页和收藏资料放进一个可搜索的记忆库

## V2EX / 开发者社区长文

标题：

```text
我做了一个 Windows 本地资料搜索工具，可以搜 PDF/Word/Excel 和截图文字
```

正文：

```text
大家好，我做了一个 Windows 桌面软件 DustySearch，主要解决一个很普通但挺烦的问题：

文件、截图、PDF、Word、Excel、网页收藏越来越多，等真的要找时，经常想不起放在哪里，也想不起文件叫什么。

DustySearch 现在能做这些事：

- 搜本机文件名
- 搜 TXT / Markdown / PDF / Word / Excel / CSV 正文
- 识别截图、照片里的文字，放进记忆库
- 把常用文件和网页导入个人记忆库
- 给资料加分类、标签和自己的备注
- 搜索结果会显示命中原因和预览
- 有资料体检，能看到索引、备份、读取失败等状态

它是本地优先的：

- 记忆库默认存在 Documents\\DustySearchData
- 不需要登录账号
- 网页摘要可以关闭
- 云同步只是使用你自己已有的网盘同步文件夹，不登录云账号

目前是 v1.0.0，Windows 可下载 zip 包，解压后运行 Start-DustySearch.cmd。

项目地址：
https://github.com/Dusty7-cloud/DustySearch

下载地址：
https://github.com/Dusty7-cloud/DustySearch/releases/latest

如果你平时也经常找不到文件、截图、资料，欢迎试试。也欢迎提建议，尤其是：

- 哪些格式最想支持？
- 搜索结果哪里还不够清楚？
- 安装和启动是否顺手？
- 你会不会用“记忆库”保存常用资料？
```

## 知乎 / 博客长文

标题：

```text
我做了一个 Windows 本地资料搜索工具：文件、正文、截图和网页都能放进一个记忆库
```

正文：

```text
我做 DustySearch 的原因很简单：电脑里的资料越来越多，但真正需要时经常找不到。

有些资料在桌面，有些在下载文件夹，有些是 PDF、Word、Excel，有些是截图，有些只是当时看过的网页。传统文件夹管理很容易越整理越乱，系统搜索也不总是够直观。

DustySearch 想解决的是这个问题：

把本机文件、常见文档正文、截图 OCR 文字、导入网页和收藏资料放到一个统一的搜索入口里。

现在它支持：

1. 本地文件名搜索
2. PDF / Word / Excel / CSV / TXT / Markdown 正文搜索
3. 图片 OCR，把截图里的文字保存进记忆库
4. 网站导入，把网页文字保存进记忆库
5. 搜索结果收藏
6. 分类、标签、个人备注
7. 资料体检，包括资料夹、索引、读取失败、备份状态
8. 本地备份、导出、同步包和网盘文件夹同步

我希望它不是一个复杂的知识管理系统，而是一个轻一点的桌面工具：

- 想找文件时，先搜
- 觉得重要时，收藏进记忆库
- 以后忘了叫什么，也可以按正文、标签、备注找回来

隐私方面，DustySearch 是本地优先的。数据默认放在电脑里的 Documents\\DustySearchData，不需要登录账号。网页摘要功能可以关闭，云同步也只是使用你自己已经同步好的本地文件夹。

现在项目已经开源，也提供了 Windows 下载包：

项目地址：
https://github.com/Dusty7-cloud/DustySearch

下载地址：
https://github.com/Dusty7-cloud/DustySearch/releases/latest

如果你也有“电脑资料太多、找东西困难”的问题，可以试试。也欢迎反馈：安装是否顺利、搜索是否符合预期、记忆库这个设计是否有用。
```

## 发布顺序建议

1. 先发朋友圈或熟人群，拿 2-3 个真实反馈。
2. 再发 V2EX 或类似开发者社区，标题强调“Windows 本地资料搜索”。
3. 如果反馈不错，再发知乎/博客长文。
4. 最后再考虑 Reddit、Product Hunt、Hacker News 这类英文平台。

## 不建议这样写

不要只写：

```text
DustySearch v1.0.0 发布了，欢迎 Star。
```

更好的写法是先说痛点：

```text
电脑里文件、截图、PDF、Word 越来越多，真正要找时经常想不起放哪里。我做了一个本地资料搜索工具 DustySearch，想解决这个问题。
```
